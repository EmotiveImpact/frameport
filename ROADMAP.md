# Frameport roadmap

## Implemented and tested foundation

The approved monochrome studio and shader, genuine HTML/React source generation, local assets, responsive evidence, editable text, export regeneration and downloads remain implemented. The platform now also has real document routes, persistent private sessions, project management, a durable SQL queue, revision-conflict detection and supervised conversion subprocesses. The full gateway-to-worker journey is tested against the original Forma fixture.

## Immediate deployment gate

Connect the Railway account, provision the persistent worker and volume, verify Chromium sandbox readiness, then set the Vercel gateway's worker origin. Exercise an actual hosted conversion, refresh/reopen, editing and both downloads. Until this is done, the live app must report that the worker is not connected. No fake readiness or temporary production project database.

## Genuine Framer acceptance

Run an authorised Framer-published marketing site through the normal sandboxed worker, build its React export and compare that output separately from HTML. Record expected behaviours and turn each discrepancy into a small reproducible fixture. The original sample's successful workflow is not a substitute for live Framer compatibility.

## Broader conversion coverage

Reconstruct breakpoint-specific DOM variants. Add tested adapters for tabs, carousels, overlays and selected scroll/motion patterns. Improve cross-page component reuse, semantic naming, CSS simplification, responsive images, media and asset provenance. Keep unsupported constructs visible rather than silently flattening them.

## Project-native context and repair

Test the read-only bridge inside genuine Framer projects. Extend metadata mapping and opt-in CMS migration with actual bindings. The current importer is not an original-canvas compiler. Build deterministic repair rules from observed failures before adding optional AI-assisted suggestions behind bounded checks.

## Public service gate

Before public signup: tenant-scoped identity and storage, stronger per-job container isolation, enforced network egress, durable external scheduling/storage at scale, billing/quotas, abuse controls, backup/restore tests and operational/security review. A private owner workspace with a volume is not a multi-tenant public SaaS.
